Discord Guide

1. Discord چیست؟

Discord یک پلتفرم ارتباطی برای چت، تماس صوتی، تماس تصویری و ساخت کامیونیتی است. کاربران می‌توانند در Serverها عضو شوند و با افراد دیگر ارتباط داشته باشند.

2. ساخت اکانت Discord

  1. Discord را باز کن.
  2. روی Register کلیک کن.
  3. ایمیل خودت را وارد کن.
  4. Username انتخاب کن.
  5. رمز عبور انتخاب کن.
  6. مراحل تأیید حساب را انجام بده.

3. Login و Logout

برای ورود به Discord روی Login بزن و ایمیل یا شماره تلفن و رمز عبورت را وارد کن.

برای خروج نیز از User Settings گزینه Log Out را انتخاب کن.

4. Server چیست؟

Server محیط اصلی کامیونیتی در Discord است. داخل Server می‌توانی Channel، Category، Role و اعضای مختلف داشته باشی.

5. ساخت Server

  1. روی علامت + در لیست Serverها کلیک کن.
  2. Create My Own را انتخاب کن.
  3. نام Server را انتخاب کن.
  4. Server را ایجاد کن.

6. Channel چیست؟

Channel محلی برای ارتباط داخل Server است. مهم‌ترین نوع‌ها عبارت‌اند از:

  • Text Channel
  • Voice Channel
  • Forum Channel
  • Announcement Channel
  • Stage Channel

7. ساخت Text Channel

  1. کنار Category روی + کلیک کن.
  2. Text Channel را انتخاب کن.
  3. نام Channel را وارد کن.
  4. Create Channel را بزن.

8. Voice Channel

Voice Channel برای صحبت صوتی استفاده می‌شود. اعضا می‌توانند وارد Voice شوند و با یکدیگر صحبت کنند.

9. Category چیست؟

Category برای مرتب کردن Channelها استفاده می‌شود. مثلاً می‌توانی یک Category به نام Community بسازی و Channelهای مربوط به کامیونیتی را داخل آن قرار بدهی.

10. Role چیست؟

Role برای مشخص کردن دسترسی و جایگاه کاربران در Server استفاده می‌شود.

  • Owner
  • Admin
  • Moderator
  • Member
  • VIP

11. Permission چیست؟

Permission مشخص می‌کند یک Role یا User چه کارهایی می‌تواند انجام دهد.

  • View Channels
  • Send Messages
  • Manage Messages
  • Manage Channels
  • Kick Members
  • Ban Members
  • Manage Roles
  • Administrator

12. Invite Link

Invite Link لینکی است که با آن می‌توانی افراد را به Server دعوت کنی.

از Server گزینه Invite People را انتخاب کن و لینک دعوت را برای فرد موردنظر بفرست.

13. Friend چیست؟

می‌توانی افراد را به لیست Friends اضافه کنی و از طریق DM با آنها صحبت کنی.

14. DM چیست؟

DM یا Direct Message یک گفت‌وگوی خصوصی بین کاربران Discord است.

15. Message

در Text Channel می‌توانی پیام ارسال کنی. روی پیام خودت می‌توانی کارهایی مثل Edit، Delete و در صورت داشتن دسترسی Pin انجام دهی.

16. Mention

با استفاده از @ می‌توانی یک کاربر یا Role را Mention کنی.

@username

17. Emoji و Sticker

Discord از Emoji و Sticker برای بیان احساسات و واکنش‌ها در پیام‌ها پشتیبانی می‌کند.

18. Voice Settings

از User Settings → Voice & Video می‌توانی Microphone و Speaker را تنظیم کنی.

19. Push To Talk

در حالت Push To Talk فقط زمانی که کلید مشخص‌شده را نگه می‌داری صدای میکروفون ارسال می‌شود.

20. Mute و Deafen

  • Mute: میکروفون خودت را خاموش می‌کند.
  • Deafen: صدای دریافت‌شده را نیز قطع می‌کند.

21. Screen Share

در Voice Channel می‌توانی صفحه یا یک پنجره را برای دیگران Share کنی، در صورتی که این قابلیت برای حساب و محیط موردنظر در دسترس باشد.

22. Video Call

Discord امکان تماس تصویری را در محیط‌های پشتیبانی‌شده فراهم می‌کند.

23. Bot چیست؟

Bot یک برنامه خودکار است که می‌تواند وظایف مختلفی در Server انجام دهد.

  • Moderation
  • Music
  • Games
  • Utilities
  • Automation

24. اضافه کردن Bot

  1. صفحه معتبر Bot را پیدا کن.
  2. گزینه Add to Discord یا Invite را انتخاب کن.
  3. Server موردنظر را انتخاب کن.
  4. Permissionهای درخواست‌شده را بررسی کن.
  5. Bot را اضافه کن.

25. Discord Developer Portal

Developer Portal محیطی برای ساخت Application و Botهای Discord است.

26. Bot Token

Bot Token اطلاعات محرمانه Bot است. آن را در اختیار دیگران قرار نده و داخل کد عمومی GitHub قرار نده.

27. امنیت Discord

  • از رمز عبور قوی استفاده کن.
  • 2FA را فعال کن.
  • روی لینک‌های ناشناس کلیک نکن.
  • Token را با کسی به اشتراک نگذار.
  • اطلاعات ورودت را در سایت‌های ناشناس وارد نکن.

28. 2FA چیست؟

Two-Factor Authentication یک لایه امنیتی اضافه برای حساب Discord است.

29. Phishing چیست؟

Phishing تلاش برای فریب دادن کاربر و گرفتن اطلاعات حساس مانند رمز عبور یا اطلاعات حساب است.

30. Block

با Block کردن یک کاربر می‌توانی ارتباط و تعامل مستقیم با آن کاربر را محدود کنی.

31. Report

اگر با محتوایی مواجه شدی که قوانین Discord را نقض می‌کند، از ابزارهای رسمی گزارش‌دهی Discord استفاده کن.

32. Kick و Ban

مدیران Server در صورت داشتن Permission مناسب می‌توانند کاربران را Kick یا Ban کنند.

  • Kick: خارج کردن کاربر از Server
  • Ban: مسدود کردن دسترسی کاربر به Server

33. Server Boost

Server Boost قابلیتی برای حمایت از Server است که می‌تواند با توجه به سطح Boost امکاناتی برای Server فراهم کند.

34. Discord Nitro

Discord Nitro یک اشتراک پولی است که امکانات و قابلیت‌های اضافه‌ای ارائه می‌دهد.

35. تنظیمات Appearance

از User Settings → Appearance می‌توانی ظاهر Discord و بعضی تنظیمات مربوط به نمایش را شخصی‌سازی کنی.

36. Notification

از User Settings → Notifications می‌توانی اعلان‌های Discord را مدیریت کنی.

37. Privacy

در بخش Privacy & Safety می‌توانی بعضی تنظیمات مربوط به پیام‌ها و ارتباطات را مدیریت کنی.

39. Thread

Thread یک گفت‌وگوی جداشده از یک پیام است که برای مرتب نگه داشتن بحث‌ها استفاده می‌شود.

40. مشکل Discord

اگر Discord باز نمی‌شود یا مشکل اتصال دارد:

  • اینترنت را بررسی کن.
  • Discord را ببند و دوباره اجرا کن.
  • برنامه را به‌روز کن.
  • در صورت نیاز نصب مجدد را امتحان کن.
  • وضعیت سرویس Discord را بررسی کن.
